Article elements

everything Hugo's markdown can emit · 720px measure

A section heading, h2

Body copy sits at 18.5 over 1.72. A link in running text takes the accent with no underline until hover, and inline code takes the surface tint. Press Ctrl K for the keyboard variant.

A subsection, h3

A long bare URL like https://github.com/winterdom/viasfora/blob/master/README.md wraps rather than blowing out the measure.1

A minor heading, h4

  • An unordered item, marker in muted grey
  • A second item that runs long enough to wrap onto a second line and shows the hanging indent
  • A third, with a nested list under it
    • One level of nesting is supported
    • Hollow marker, same indent
  1. Numbers are mono and muted
  2. Same metrics as the bullet list

A pull quote is Newsreader italic with a two-pixel accent rule. No quotation marks, no attribution line unless the source is named.

Note

A callout is a surface fill with a mono label. No icon, no coloured left border, no emoji. Use it for asides the reader can skip.

No zebra striping, no outer border, no vertical rules. A wide table scrolls inside its own container.

Notes

1 Footnotes land here, above the byline, with a return arrow back to the reference. ↩

Spacing rules

26px between block elements, always.

+18px above an h2, +12px above an h3, +8px above an h4.

40px either side of a horizontal rule.

First element after the title block and last before the byline get no extra margin.

Syntax tokens

.k .kd .kt — keywords
.s .s1 .s2 — strings
.c .c1 .cm — comments
.na .nt .nf — names
.m .mi .nb — numbers
.o .p — punctuation

Six colours, not twenty. Anything unmapped inherits plain text.
